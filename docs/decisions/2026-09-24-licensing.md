# Licensing: repository code MIT, template MIT-0

Date: 2026-09-24

## Decision

This repository's own code is licensed MIT. Everything under `template/` is licensed MIT-0, so
generated projects carry no attribution requirement. Third-party files keep their own licenses, and
each generated project chooses its own license.

## Reason

MIT-0 keeps the promise that generated projects belong entirely to their users. Ordinary MIT would
require attribution. Choosing the license before any template content is written means nothing has
to be relicensed later.

## Alternatives considered

- CC0 for the template.
- MIT for both repository code and template.
